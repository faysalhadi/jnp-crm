STEP 3 — NEW FILE: src/utils/bulk.js
════════════════════════════════════════════════════════════════════════
 
Pure helpers. No React, no supabase.
 
  export function modelKey(brand, model)
    lowercase, trim, collapse whitespace, strip punctuation ( / - , " ' )
    return `${brand}|${model}`, or null if either is missing.
    Do NOT fuzzy-match. Predictable grouping beats clever grouping.
 
  export function dealTotal(deal)
    (deal.unit_price || 0) * (deal.quantity || 1)
    Use this everywhere a deal value is displayed. Never read `value` directly
    for new code.
 
  export function buildStockPools(stockRows, holds)
    Group available stock by modelKey. For each pool return:
      { key, brand, model, label,
        total,      // sum of quantity across rows in this group
        held,       // sum of quantity across ACTIVE holds for this key
        sold,       // sum of quantity where status === 'sold'
        free,       // total - held  (never below 0)
        minPrice, maxPrice }  // from the rows
 
    IMPORTANT: some rows will have quantity 1 (older per-unit entries) and some
    will have quantity 50. Summing handles both. Do NOT try to consolidate or
    rewrite existing rows — group on read.
 
  export function isHoldActive(hold)
    released_at is null AND expires_at is in the future.
    Expiry is COMPUTED, never stored. There is no cron and no background job.
    A hold past its expiry is simply treated as released everywhere.
 
  export function holdRemaining(hold)
    "31h left" · "4h left" · "42m left" · "" when inactive.
 
  export function sourcingAge(deal)
    Hours since sourcing_started_at.
    Return { hours, level } where level is:
      'ok'      under 24h
      'warn'    24–48h
      'late'    over 48h
    Faisal loses the customer after about two days — these thresholds encode that.

  import { supabase } from "../supabase";
 
  export async function placeHold({ brand, model, quantity, dealId, customerId, hours = 48 })

    { ok:false, insufficient:true, free }. Otherwise insert into stock_holds
    with held_by = current user and expires_at = now + hours.
 
  export async function releaseHold(holdId)
    Set released_at = now().
 
  export async function releaseHoldsForDeal(dealId)
    Release every active hold attached to that deal.
 
  export async function extendHold(holdId, hours = 48)
    Push expires_at out from now.
 
  export async function getHolds(modelKeys)
    Fetch active holds for a set of model keys. Used by buildStockPools.
 
Current user: use the existing AuthContext if it exposes an id, otherwise
supabase.auth.getUser(). Do NOT add a new auth mechanism.
 
Every function returns { ok:true, ... } or { ok:false, error }. Never throws.

STEP 5 — NEW FILE: src/services/parkService.js
════════════════════════════════════════════════════════════════════════
 
  export async function parkDeal(dealId, { reason, targetUnitPrice, note })
 
  Does all of this, in order:
    1. deals: stage='parked', parked_reason=reason, parked_at=now(),
       target_unit_price = targetUnitPrice (when given)
    2. releaseHoldsForDeal(dealId) — parked deals never hold inventory
    3. follow_ups: mark any pending row for this customer status='done'
    4. activity_log: activity_type='note',
       note = "Parked: <reason label>" + (targetUnitPrice ? " — offered AED x/unit" : "")
                                       + (note ? " · " + note : "")
 
  export async function unparkDeal(dealId, newStage = 'new_inquiry')
    Clear parked_reason and parked_at. KEEP target_unit_price — that number
    stays valuable history.
 
Returns { ok } shape. Never throws.
