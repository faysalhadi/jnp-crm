CHANGE 1 — Move parts sold loading to PartsContext

In src/context/PartsContext.js add a new function
loadPartsSold inside PartsProvider:

  async function loadPartsSold() {
    setPartsSoldLoading(true);
    const { data } = await supabase
      .from("parts_sales")
      .select("*")
      .order("sold_at", { ascending: false });
    setPartsSold(data || []);
    setPartsSoldLoading(false);
  }

Add loadPartsSold to the context Provider value:
  loadPartsSold,

Export it from the context.

CHANGE 2 — Update App.js to use loadPartsSold from context

In App.js add loadPartsSold to the useParts destructuring:
  const {
    ...existing,
    loadPartsSold,
  } = useParts();

Find this useEffect in App.js:
  useEffect(() => {
    if (stockFilter !== "parts_sold") return;
    setPartsSoldLoading(true);
    supabase.from("parts_sales").select("*")
      .order("sold_at", { ascending: false })
      .then(({ data }) => { 
        setPartsSold(data || []); 
        setPartsSoldLoading(false); 
      });
  }, [stockFilter]);

Replace with:
  useEffect(() => {
    if (stockFilter !== "parts_sold") return;
    loadPartsSold();
  }, [stockFilter, loadPartsSold]);
