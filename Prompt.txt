═══════════════════════════════════════

The trader_inventory table has a source_group column. We need to track the last import timestamp per group and skip messages older than that.

CHANGE A — Add a new state variable after existing state declarations:
const [lastImportTimes, setLastImportTimes] = useState({});

CHANGE B — In loadTraderListings function, after loading listings, also load last import times:

Add this after setTraderListings(data || []):

const { data: importTimes } = await supabase
  .from("trader_inventory")
  .select("source_group, created_at")
  .order("created_at", { ascending: false });

if (importTimes) {
  const times = {};
  for (const row of importTimes) {
    if (!times[row.source_group]) {
      times[row.source_group] = row.created_at;
    }
  }
  setLastImportTimes(times);
}
