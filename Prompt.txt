Read src/context/TradersContext.js fully before making changes.

CHANGE 1 — Get activeDeal from CustomerContext 
instead of props

In TradersContext.js add this import at the top:
  import { useCustomers } from "./CustomerContext";

Find the TradersProvider function signature:
  export function TradersProvider({ children, anthropicKey, activeDeal }) {

Replace with:
  export function TradersProvider({ children, anthropicKey }) {

Add this line at the very top of TradersProvider function body:
  const { activeDeal } = useCustomers();

Now activeDeal is always the current active deal
from CustomerContext, not a stale prop value.

CHANGE 2 — Update TradersProvider in App.js

Find where TradersProvider wraps the return in App.js:
  <TradersProvider 
    anthropicKey={anthropicKey} 
    activeDeal={activeDeal}
  >

Replace with:
  <TradersProvider anthropicKey={anthropicKey}>

Remove activeDeal prop since TradersContext 
now gets it directly from CustomerContext.

CHANGE 3 — Move TradersProvider to index.js

Since TradersProvider now uses useCustomers hook,
it must be wrapped INSIDE CustomerProvider.

In src/index.js update:
  import { CustomerProvider } from './context/CustomerContext';
  import { StockProvider } from './context/StockContext';
  import { UIProvider } from './context/UIContext';
  import { SalesProvider } from './context/SalesContext';
  import { PartsProvider } from './context/PartsContext';
  import { TradersProvider } from './context/TradersContext';

  root.render(
    <UIProvider>
      <SalesProvider>
        <PartsProvider>
          <CustomerProvider>
            <TradersProvider anthropicKey={
              localStorage.getItem("jnp_anthropic_key") || ""
            }>
              <StockProvider>
                <App />
              </StockProvider>
            </TradersProvider>
          </CustomerProvider>
        </PartsProvider>
      </SalesProvider>
    </UIProvider>
  );

CHANGE 4 — Remove TradersProvider wrapper from App.js

Find in App.js main return:
  return (
    <TradersProvider anthropicKey={anthropicKey}>
      ... content ...
    </TradersProvider>
  );

Remove the TradersProvider wrapper and keep just:
  return (
    ... content ...
  );

Also remove the TradersProvider import from App.js.

NOTE: The anthropicKey in index.js is read from 
localStorage directly since App state is not 
available there. The key is already saved to 
localStorage when user enters it.
